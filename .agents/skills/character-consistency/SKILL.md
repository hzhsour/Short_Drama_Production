# 人物一致性

## 建立角色基线

- 为角色分配稳定 ID，如 `CHAR-001`；姓名变化、别名和关系与 ID 关联。
- 将叙事事实与视觉特征分开：身份/动机/关系/经历；年龄范围/脸型/肤色/发型/体态/服装/标志物/色彩。
- 明确稳定特征、可变特征、故事导致的变化与禁止漂移项。记录服装、伤痕、道具和左右侧。
- 参考素材注明路径、版本、来源和授权状态；未知项明确写“未知/待确认”。

## 连续性审阅

逐镜对照人物 ID 和角色圣经，检查年龄感、发型、服装、配饰、体态、伤痕、情绪状态、动作方向及与其他角色的位置关系。跨场变化需有时间或剧情依据。生成提示的固定身份描述保持相同顺序和关键词，动作/光线/镜头描述单独追加。

发现冲突时列出镜头 ID、圣经规则、冲突内容和建议修正；不要静默改写已经确认的设定。将通过审核的提示版本和参考图路径记录到分镜或素材说明中。
