# 项目章程

## 愿景

建立一条可检查、可迭代的中文短剧生产线，让一个创意从系列设定、剧本和人物资产，进入镜头计划、生成素材、合成和交付。

## 默认制作约定

- 画幅：9:16 竖屏；预览合成使用 1080 × 1920、30 fps。正式项目可在项目圣经中覆盖这些默认值。
- 每集时长、集数、目标平台、分级、调性、预算和 AI 工具由项目发起人确认；模板中的空白项保持待定。
- 先保证人物动机和情节因果，再优化镜头、生成提示和后期效果。
- 先用故事板中的 `duration_frames` 锁定时间，再根据实际素材调整；每次调整同步台词、字幕和音频时间码。
- AI 视频、配音及音乐提供商是可选项。未明确获准时只准备提示词、清单和本地后期工程，不发起外部生成请求。

## 阶段与交付

1. **开发**：项目圣经、人物关系、分集梗概和剧本。
2. **视觉设计**：人物/场景参考页、连续性规则、提示词版本。
3. **预制**：结构化分镜、素材清单、声音与字幕计划。
4. **素材制作**：逐镜制作、记录来源和人工审核。
5. **合成与后期**：Remotion 工程、FFmpeg 处理记录、成片规格检查。
6. **归档**：剧本/分镜版本、素材来源、渲染参数、成片校验和。
