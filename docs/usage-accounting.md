# 生成用量、预算与费用对账

本轮只用模拟 HTTP 返回验证，不查询服务商账单、不充值、不设置用户预算、不生成可用于 Live 的批准文件。以下字段不能称为实际扣费。

| 字段 | 含义 |
| --- | --- |
| `estimated_cost` | 提交前由请求规格和配置费率推算的金额；不是最高收费承诺 |
| `reserved_budget` | 已提交或可能提交的任务在共享账本中保留的预算；尚未预留为 `null` |
| `provider_usage.completion_tokens` | 服务商返回的输出 token；未知保持未知，不能由估算倒推冒充 |
| `provider_task_metadata` | 服务商任务、模型、分辨率、帧率等白名单信息，另保留请求规格 |
| `provider_usage_latest` / `provider_usage_observations` | 最新及去重后的用量观察；主用量保留已观察最高值用于保守控制，`provider_usage_basis` 说明依据 |
| `calculated_cost` | 返回用量乘以请求绑定的已核实适用费率；不是最终账单或账户扣款 |
| `billing_reconciliation_status` | `awaiting_provider_usage`、`provider_usage_unpriced`、`pending_final_invoice` 或本地 Mock 非计费状态；不会自动标成账单已核对 |

当前可计算的真实服务计费形式是已核实的无输入视频、1080p 输出 token 费率。报价需在提交时有效，模型与返回规格需符合适用范围；不适用时保留用量、标明待复核，不套用其他地区/分辨率价格。源 `usage` 中只接受非负整数 token，不保存完整原始 HTTP 响应、认证头或带签名下载 URL。

## 保守停止规则

- 提交前在 SQLite 事务中预留预算，所有剧集使用同一项目账本；未知提交、失败或用量未知不自动释放预留。
- 已知费用暴露按每任务 `max(原预留, 已计算金额)` 汇总。后续较小/缺失返回不会冲掉已观察的较高金额，用量观察仍可追溯。
- 算价高于估算，或模型/输出规格使费率不再适用时，持久阻断新增付费任务，等待人工复核。
- 已有暴露达到每集/整部剧限额，或已有任务费用高于单任务限额时，不再接受新增付费提交。恢复原已接受任务仍可查询和下载。
- 上述门控只能停止未来提交。已接受任务的最终收费由服务商决定，存在在途任务和计费调整，不能将估算或预留称为绝对费用上限。

最终账单核对需要用户取得服务商正式账单/扣费记录，按任务 ID、模型、计费币种、用量和适用费率人工核对。本项目本轮没有实现账单 API、自动核销或预算释放命令，也不会通过修改审批或清空账本绕过费用复核。
